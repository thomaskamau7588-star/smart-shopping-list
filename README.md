
# Smart Shopping List 

## Description
Smart Shopping List is a web application designed to help users organize their shopping, manage expenses, and track purchased and remaining items.

Users can add, edit, delete, search, and filter shopping items while monitoring their estimated shopping costs in Kenyan Shillings (KSh).

## Features
- User registration and login.
- Add shopping items with quantity, category, and price.
- Edit existing shopping items.
- Delete shopping items.
- Mark items as purchased or pending.
- Search items by name.
- Filter items by category and purchase status.
- View total, purchased, and remaining items.
- Automatically calculate estimated shopping costs.
- Save shopping data using localStorage.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Browser localStorage

## JavaScript Concepts Applied
- Variables and functions
- Arrays and objects
- Array methods (map, filter, find, reduce)
- Event listeners
- Conditional statements
- Spread syntax
- DOM manipulation
- Local storage

## Currency
All shopping expenses are calculated and displayed in Kenyan Shillings (KSh).

## Theme
The application uses a green and white color theme to provide a clean and user-friendly interface.
